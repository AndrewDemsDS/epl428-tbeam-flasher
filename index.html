t-beam flasher / C ↔ MicroPython

LilyGO T-Beam S3 Supreme (ESP32-S3). Swaps the firmware over Web Serial. Nothing leaves the browser.

Web Serial is not available in this browser. Use Chrome, Edge or Opera on desktop, over HTTPS or localhost.

1. Pick a direction

C → MicroPython

Writes a MicroPython build for the ESP32-S3 at flash address 0.

MicroPython → C

Restores the LilyGO factory image (the C demo that shows text on the screen). Fetched from the LilyGO repo at flash time.

1b. Custom firmware with a TensorFlow Lite model

MicroPython plus TensorFlow Lite for Microcontrollers (microlite), with a .tflite model frozen into flash as the module tflm_model. It is compiled by a GitHub Actions job in this repo, not in your browser. Keep models small: the frozen copy sits in flash and is copied to RAM at tflm_model.load().

2. Options

If the board is not found
  • The ESP32-S3 USB port resets itself into the bootloader. If connecting fails, hold BOOT while plugging in USB, then try again.
  • After flashing, the page resets the board. Unplug and replug if the port does not come back.
  • Close Thonny, mpremote, a serial monitor or any other tab that holds the port.
  • Linux: your user needs the uucp or dialout group for /dev/ttyACM0.
